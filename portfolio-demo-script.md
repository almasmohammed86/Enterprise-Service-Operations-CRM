# Portfolio demo script (5–7 minutes)

1. **Business problem (45 sec):** Explain how service teams need consistent case intake, SLA visibility, and reliable integration monitoring.
2. **Data model (60 sec):** Show Service Case, Account, Contact, Service Asset, Entitlement, and Integration Log relationships.
3. **Client/server validation (90 sec):** Demonstrate form JavaScript validation, then explain why the synchronous plug-in enforces the same critical rules for API/import callers.
4. **SLA logic (60 sec):** Create cases with different severities and show target calculation.
5. **Automation (60 sec):** Walk through the SLA warning and integration-failure flows and their guard conditions.
6. **Security (45 sec):** Compare Service Agent and Service Manager permissions using separate test accounts.
7. **Integration and operations (60 sec):** Show the HTTP examples, correlation ID strategy, and Integration Log diagnostics.
8. **ALM and testing (45 sec):** Explain solution packaging, environment variables, connection references, test cases, and deployment checklist.

Be transparent: label this as a portfolio reference implementation unless you have personally built and verified every component in a live environment.
